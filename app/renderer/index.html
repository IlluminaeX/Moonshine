Pair a device by hand

One-time code

            
For apps that pair with a code instead of a PIN (Artemis). Pick a passphrase, then enter the code and the passphrase on the device within 3 minutes.

Before and after every app

                
“Do” runs before an app starts and “Undo” after it ends. If a “Do” command fails, the app doesn’t start.
